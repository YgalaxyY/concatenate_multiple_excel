# Excel Merge Core

Учебный прототип Python-утилиты для объединения нескольких XLSX-выгрузок в один отчёт.

## Пример

В первой выгрузке две строки — `A, 10` и `B, 20`. Во второй — `C, 30`. В итоговой книге три строки. Утилита считывает данные из файлов в текущей папке, исключает `report.xlsx` из входных данных и объединяет строки через pandas.

## Где посмотреть

[Код утилиты](COOPERATE.py) · [Зависимости](requirements.txt) · [Инструкция по запуску](README.md#try-it-with-sample-data)

Для проверки используйте отдельную папку, копии входных таблиц и пустой `report.xlsx` с листом `Sheet1`. Прототип считает заголовки обычными строками и ожидает готовую выходную книгу. Для задачи с разными форматами выгрузок первым шагом будет сверка названий и порядка столбцов.
